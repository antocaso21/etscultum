# CULTUM ETS – tutti i file sullo stesso livello

Questa versione NON contiene cartelle. TUTTI i file, comprese le fotografie, vanno caricati singolarmente nella root del repository GitHub, accanto a `index.html`.

1. Crea un repository pubblico (es. `cultum-site`) su GitHub.
2. Dentro il repository apri **Add file > Upload files**, seleziona e trascina TUTTI i file di questo pacchetto (NON lo ZIP).
3. Premi **Commit changes**.
4. Vai in **Settings > Pages**, scegli **Deploy from a branch**, poi **main** e **/(root)**, quindi **Save**.
5. Controlla il link `https://TUO-USERNAME.github.io/cultum-site/`.

**Alternative semplicissima:** puoi anche caricare il singolo `index.html` del pacchetto **CULTUM_UN_SOLO_FILE**: contiene già CSS, JavaScript e immagini e non richiede altri file.
